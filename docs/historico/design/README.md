# Rascunhos de design — Coleta Automática

Mockups em HTML do brainstorm que precedeu a tela **Coleta Automática**
(o design está descrito em
[`../superpowers/specs/2026-10-20-coleta-automatica-design.md`](../superpowers/specs/2026-10-20-coleta-automatica-design.md)).

Cada arquivo é uma versão do rascunho, na ordem em que foram produzidos:

| Arquivo | Versão |
|---|---|
| `tela-coleta-automatica.html` | v1 — primeira ideia |
| `tela-coleta-automatica-v2.html` | v2 |
| `tela-coleta-automatica-v3.html` | v3 — **aprovada** (a base que virou o código) |
| `tela-coleta-automatica-v3b.html` | v3b — ajuste do card de download |
| `tela-coleta-automatica-v3c.html` | v3c — ajuste do botão de ação |
| `tela-coleta-automatica-v4.html` | v4 — Orientedações na lateral |
| `tela-coleta-automatica-v5.html` | v5 — pilha em largura total |
| `tela-coleta-automatica-v6.html` | v6 — desfeita (a pilha em largura total esvaziava a linha) |

> **Arquivo histórico.** O rascunho v6 foi desfeito: a tela final usa a
> coluna de Orientações à direita, como as demais aplicações do HUB. Os
> arquivos são preservados para registrar as alternativas consideradas.

Para abrir: arraste o `.html` para o navegador (são arquivos isolados, sem
dependência externa).
